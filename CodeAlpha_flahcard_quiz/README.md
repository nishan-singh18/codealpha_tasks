# 📚 Flashcard Quiz Pro

A modern and interactive **Flashcard Quiz** web application designed to make learning engaging and efficient. Users can create, organize, and study flashcards while tracking their learning progress through an intuitive interface.

---

## 🚀 Features

- 📖 Study flashcards one by one
- ➕ Add custom flashcards
- 🗂️ Manage flashcard collection
- 🏷️ Organize cards by categories
- 🔀 Shuffle flashcard deck
- 📊 Progress tracking
- 🏆 Mastered card counter
- 👁️ Show/Hide answers
- ⏮️ Previous & Next navigation
- 🌙 Dark mode interface
- 🔊 Sound toggle
- ⌨️ Keyboard shortcuts for quick navigation
- 📱 Responsive design for desktop and mobile

---

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Double-click **quiz_card.html** or open it in any modern web browser.

No installation or external libraries are required.
