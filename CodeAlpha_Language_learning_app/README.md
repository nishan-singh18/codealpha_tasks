# 🌍 LingoPulse – AI Language Learning Platform

LingoPulse is a modern AI-powered language learning web application designed to help users learn new languages through interactive flashcards, quizzes, grammar lessons, and an AI conversation tutor.

This project is built as a **single standalone HTML file**, making it lightweight, portable, and easy to run without any installation or external dependencies.
